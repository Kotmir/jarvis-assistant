================================================================================
🤖 GIT AUTOPUSH — АВТОМАТИЧЕСКИЕ КОММИТЫ
================================================================================

ЧТО ЭТО:

Скрипт который автоматически:
  1. Обнаруживает изменения в репо
  2. Добавляет файлы (git add -A)
  3. Создаёт коммит с умным сообщением
  4. Отправляет на GitHub (git push)

СООБЩЕНИЕ КОММИТА:
  🤖 Обновлено 3 файлов | Добавлено 1 новых [12:34:56] by KotMir

КАК ИСПОЛЬЗОВАТЬ:

# Один раз (когда захочешь)
python git_autopush.py --once

# Демон (проверяет каждые 5 минут)
python git_autopush.py --daemon

# Каждые 60 сек
python git_autopush.py --daemon --interval 60

# Сухой прогон (показать что будет)
python git_autopush.py --dry-run

# На Windows — просто двойной клик
autopush.bat
