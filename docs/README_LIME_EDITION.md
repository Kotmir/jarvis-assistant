## 🤖 AutoPush: Как использовать

### Вариант 1: Один раз (когда захочешь)
```bash
python git_autopush.py --once
```

### Вариант 2: Демон (фоном)
```bash
# Проверка каждые 300 сек (5 минут)
python git_autopush.py --daemon

# Или каждые 60 сек
python git_autopush.py --daemon --interval 60

# Ctrl+C для выхода
```

### Вариант 3: Windows батник
```bash
# Один раз
autopush.bat

# Демон
autopush.bat daemon

# Сухой прогон
autopush.bat dry-run
```

### Что происходит при коммите

1. ✅ Обнаруживает изменения в репо (`git status`)
2. ✅ Добавляет все файлы (`git add -A`)
3. ✅ Создаёт коммит с умным сообщением
4. ✅ Отправляет на GitHub (`git push`)

**Пример вывода**:
```
[12:34:57] ━━━ AutoPush запущен ━━━
[12:34:57] Найдено: 3 изменений, 1 новых, 0 удалено
[12:34:58] ✓ Коммит: 🤖 Обновлено 3 файлов | Добавлено 1 новых [12:34:58] by KotMir
[12:34:59] ✓ Отправлено в main
[12:34:59] ✓ AutoPush успешно завершен!
```

## 🔒 Безопасность

### ✅ Защита API ключей
- `.env` файл **НЕ** коммитится (в `.gitignore`)
- Ключи OpenAI, Gemini, Spotify хранятся только локально
- AutoPush не трогает секретные файлы

### ✅ Настройка Git
```bash
# Задать имя пользователя (один раз)
git config user.name "KotMir"
git config user.email "leula2001@outlook.com"

# Проверить
git config user.name
```

### ⚠️ Проверить перед первым коммитом
```bash
# Убедиться что .env не попадёт в Git
git status                    # не должна показать .env
cat .gitignore | grep ".env"  # должна показать ".env"
```
