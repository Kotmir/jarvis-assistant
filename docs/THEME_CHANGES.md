# 🟢 J.A.R.V.I.S. — Лайм-хакерская тема

## Изменения дизайна

### Цветовая схема
- **Основной акцент**: `#00ff00` — неоновая лайм-зелень 🟢
- **Вторичный**: `#00cc00` — более тёмный зелёный
- **Выделение**: `#ffff00` — жёлтый (слушание, активность)
- **Опасность**: `#ff0055` — красный для ошибок
- **Кибер-акцент**: `#00ccff` — голубой для инструментов
- **Фон**: `#0a0e1a` — почти чёрный (ночной режим)

### Визуальные эффекты
- ✨ **Text-shadow** на всех заголовках и активных элементах для свечения
- 🟢 **Неоновые границы** вместо мягких градиентов
- ⚡ **Box-shadow** на интерактивных элементах для киберпанка
- 📊 **Матричный стиль** в логах и событиях

### Ключевые изменения элементов

#### Шапка (Brand Section)
```css
#brand: лайм-зелень с text-shadow (неоновое свечение)
#brandState:
  - listening: жёлтый (внимание)
  - thinking: зелёный (обработка)
  - executing: голубой (действие)
  - speaking: жёлтый (говорит)
  - error: красный (ошибка)
```

#### Панели (HUD Panels)
- Зелёные границы `#00ff00` вместо голубых
- Матричный стиль с `box-shadow`
- Метрики светятся зелёным

#### Командная строка (Command Bar)
- Граница `#00ff00` с интенсивным свечением
- Микрофон светится жёлтым при активации
- Кнопка "Send" с зелёным свечением

#### Логи событий (Timeline)
- Левая граница события зелёная вместо голубой
- Теги с цветными границами и полупрозрачным фоном
- Монофонт для хакера-стиля

#### Прогресс-бары
- Нормальный прогресс: лайм-зелёный `#00ff00`
- При нагрузке: оранжевый → красный `#ff0055`

## Как использовать

### 1. Замени файл темы
```bash
cp style_lime.py jarvis/ui/style.py
```

### 2. Запусти JARVIS
```bash
python main.py              # GUI с новой темой
python main.py --cli        # Консоль
```

### 3. Переключение тем (в интерфейсе)
Если будут добавлены другие темы, выбор будет в Настройки → Оформление
